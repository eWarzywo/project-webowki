🗄️ Bazy danych (SQL)

Podstawowe komendy SQL

-- SELECT - pobieranie danych
SELECT kolumna1, kolumna2 FROM tabela WHERE warunek;
SELECT * FROM users WHERE age > 18;

-- INSERT - dodawanie danych
INSERT INTO tabela (kolumna1, kolumna2) VALUES (wartość1, wartość2);

-- UPDATE - aktualizacja danych
UPDATE tabela SET kolumna1 = wartość WHERE warunek;

-- DELETE - usuwanie danych
DELETE FROM tabela WHERE warunek;

-- JOIN - łączenie tabel
SELECT * FROM tabela1 INNER JOIN tabela2 ON tabela1.id = tabela2.id;

Funkcje agregujące

  • COUNT() - zlicza wiersze
  • SUM() - suma wartości
  • AVG() - średnia
  • MAX() - wartość maksymalna
  • MIN() - wartość minimalna
  • GROUP BY - grupowanie wyników
  • HAVING - filtrowanie grup

Typy danych SQL

  • INT - liczby całkowite
  • VARCHAR(n) - tekst o zmiennej długości
  • TEXT - długi tekst
  • DATE - data
  • DATETIME - data i czas
  • BOOLEAN - wartość logiczna
  • DECIMAL(p,s) - liczby dziesiętne

💻 Programowanie

Podstawowe koncepcje OOP

  • Klasa - szablon obiektu
  • Obiekt - instancja klasy
  • Dziedziczenie - przejmowanie właściwości klasy bazowej
  • Polimorfizm - wiele form tego samego interfejsu
  • Enkapsulacja - ukrywanie danych
  • Abstrakcja - uproszczenie złożoności

Struktury danych

  • Tablica - liniowa struktura danych
  • Lista - dynamiczna kolekcja elementów
  • Stos (Stack) - LIFO (Last In, First Out)
  • Kolejka (Queue) - FIFO (First In, First Out)
  • Drzewo - hierarchiczna struktura
  • Graf - węzły połączone krawędziami

Złożoność algorytmów (Big O)

  • O(1) - stała
  • O(log n) - logarytmiczna
  • O(n) - liniowa
  • O(n log n) - liniowo-logarytmiczna
  • O(n²) - kwadratowa
  • O(2ⁿ) - wykładnicza

🌐 Sieci komputerowe

Model OSI (7 warstw)

  1. Fizyczna - transmisja bitów (kable, hub)
  2. Łącza danych - ramki, MAC (switch, bridge)
  3. Sieciowa - routing, IP (router)
  4. Transportowa - segmenty, TCP/UDP
  5. Sesji - zarządzanie sesjami
  6. Prezentacji - format danych, szyfrowanie
  7. Aplikacji - protokoły aplikacji (HTTP, FTP)

Protokoły sieciowe

  • HTTP/HTTPS - przeglądanie stron www
  • FTP - transfer plików
  • SMTP - wysyłanie e-mail
  • POP3/IMAP - odbieranie e-mail
  • DNS - tłumaczenie nazw na IP
  • DHCP - automatyczne przydzielanie IP
  • TCP - niezawodny protokół transportowy
  • UDP - szybki, niezawodny protokół

Klasy adresów IP (IPv4)

  • Klasa A - 0.0.0.0 - 127.255.255.255 (maska /8)
  • Klasa B - 128.0.0.0 - 191.255.255.255 (maska /16)
  • Klasa C - 192.0.0.0 - 223.255.255.255 (maska /24)
  • Adresy prywatne:
    • 10.0.0.0 - 10.255.255.255
    • 172.16.0.0 - 172.31.255.255
    • 192.168.0.0 - 192.168.255.255

🔒 Bezpieczeństwo

Zagrożenia bezpieczeństwa

  • Malware - złośliwe oprogramowanie
  • Virus - replikuje się i zaraża pliki
  • Trojan - udaje legalne oprogramowanie
  • Ransomware - szyfruje dane i żąda okupu
  • Phishing - wyłudzanie danych
  • SQL Injection - atak na bazę danych
  • XSS - Cross-Site Scripting
  • DDoS - atak przeciążenia

Metody zabezpieczeń

  • Firewall - filtrowanie ruchu sieciowego
  • Antivirus - ochrona przed malware
  • Szyfrowanie - kodowanie danych (AES, RSA)
  • SSL/TLS - szyfrowanie transmisji
  • VPN - wirtualna sieć prywatna
  • 2FA/MFA - uwierzytelnianie wieloskładnikowe
  • Backup - kopie zapasowe danych
  • Haszowanie - jednostronne kodowanie (MD5, SHA)

RODO - Podstawowe zasady

  • Przetwarzanie danych tylko za zgodą
  • Minimalizacja zbieranych danych
  • Prawo do usunięcia danych
  • Prawo do przenoszenia danych
  • Obowiązek zabezpieczenia danych
  • Zgłaszanie naruszeń w ciągu 72h

💡 Wskazówki do egzaminu

  • Zawsze czytaj dokładnie polecenia
  • Sprawdzaj składnię SQL i nazwy kolumn
  • W zadaniach praktycznych testuj kod na bieżąco
  • Pamiętaj o walidacji danych użytkownika
  • Dbaj o czytelność i komentarze w kodzie
  • Zwracaj uwagę na wielkość liter (case sensitivity)
  • Zarządzaj czasem - nie spędzaj zbyt długo na jednym zadaniu
  • Zachowaj pliki w odpowiednim formacie i lokalizacji
